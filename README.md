# Nexa Website Clone

Nexa is a modern website UI clone built using React and CSS. The project focuses on recreating a professional-looking website with a dark theme, purple accents, and multiple pages.

The website introduces Nexa, provides information about the project through an About page, and includes a Contact page with a form layout.

## What Does It Do?

- Home Page: Introduces Nexa with a headline, a short description, and action buttons.
- About Page: Displays information about Nexa along with a styled layout and achievement section.
- Contact Page: Provides contact information and a form interface where users can enter their details and a message.
- Navigation: Allows users to switch between the Home, About, and Contact pages using React Router.

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- React Router
- Vite

## What I Practised

- Building UI components with React
- Setting up page navigation using React Router
- Managing input values with `useState`
- Creating layouts with CSS Flexbox
- Styling images, buttons, and page sections

## Getting Started

Open the project folder:

```bash
cd react-routing-project
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
